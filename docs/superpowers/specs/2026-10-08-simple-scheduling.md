# Simple recurring scheduling design
Approved in chat: replace complex form with WINDOW (Run during a window), REMINDER (Remind me at set times), EVENT (Promote an event). Display human-readable Eastern dates/times everywhere. LibAddonMenuDatePicker calendar controls required; time separate. No duplicate First event field.
WINDOW requires start/end only. REMINDER requires a date/time and recurrence; no event/end input, prepares once per occurrence while online, short eligibility grace avoids offline backlog. EVENT uses event date/time, promotion lead days and end delay minutes; default three phases BEFORE/DAY/LIVE, eligible message pools randomly selected using existing selection. Multiple phase assignments allowed, interval overrides and phaseOnce.LIVE supported. Defaults preserve legacy EVENT schedules, no automatic activation until Save.
Recurrence: NONE, DAILY, WEEKLY, BIWEEKLY, MONTHLY_DATE, MONTHLY_WEEKDAY, selected weekdays for weekly/daily reminders, optional custom interval. Anchor to first selected date; preserve ET wall clock across DST. Missing month days and nonexistent spring times skip occurrence; ambiguous fall uses earliest unless legacy explicit fold retained. Monthly weekday means ordinal weekday (e.g. third Friday) anchored from date. Preview next three occurrences. Recurrence is a separate schedule repeat from message repeat within window.
Only current occurrence executes; no offline backlog. Multiple repeat command/guild schedules continue sharing queue; one Zone automation as before. Existing peer channel/guild matching and jitter, edited-input safety, import/export all maintained. Status readable engaged/waiting/paused/finished. Message choice checklist with previews in phase submenus, no numeric message entry.
Dependency exact name LibAddonMenuDatePicker. DatePicker timestamp is a date carrier, not final ET instant; inspect upstream widget conversion before adapter implementation. Save revalidates transactionally. Existing full settings exports and old schedules remain compatible; persist recurrence and pools in export/import.
