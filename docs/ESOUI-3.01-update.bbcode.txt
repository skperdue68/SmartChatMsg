[B][SIZE=4]SmartChatMsg 3.01[/SIZE][/B]

A comprehensive update to the original announcement addon: reusable custom commands now sit alongside a native event planner, recurring schedules, multiple promotion periods, richer message substitutions and tools for coordinating announcements with other players.

[B]New in 3.01: optional condensed dates and times[/B]
[LIST]
[*]Use condensed dates and times is a separate checkbox for each command and guild, available in the original settings and custom Event Planner.
[*]It defaults to off, preserving standard output. Enable it for dates such as 11/03 and times such as 8PM ET or 645PM ET, plus shortened weekday/date references.
[*]Offset and named important-time substitutions follow the same choice. Literal text is unchanged.
[*]Incoming matching recognizes both standard and condensed generated wording. The choice is included in settings and event transfers.
[/LIST]

[B]Plan and manage events directly in ESO[/B]
[LIST]
[*]Open /scm schedule for a resizable three-column Event Planner: commands/events, independently scrolling period cards and a full editor. /scm retains the original settings interface.
[*]Edit events, period message pools, names and templates, recurrence, availability and advanced rules in the native window. Global and guild settings and import/export are available there too.
[*]Private drafts use Save changes and Cancel; live usage and cooldown history is retained when saving.
[*]The selected editing card and the active saved period have distinct indicators. Next eligible updates live with startup delay, cooldowns, spacing and limits.
[*]Test previews substitutions locally without preparing outgoing chat. Copy exports using the focused, selected text field and Ctrl+C.
[/LIST]

[B]Keep ordinary commands or use schedules[/B]
[LIST]
[*]On Demand custom commands, Startup delivery and automatic zone-arrival preparation remain available per command/guild.
[*]Select Guild, Officer, Zone or Group output, independent message pools, repeat frequency, cooldown, retry delay and notification sound.
[*]Message names, enablement, live template character counts and parsed previews make large libraries easier to manage.
[*]/scm off suspends scheduled sending across reloads; /scm on resumes eligible periods. Ordinary commands and incoming monitoring remain available.
[*]/scm retry can restore an eligible unsent announcement during the current UI session. /scm send requests an extra announcement from an eligible scheduled period; it respects normal safety and limits.
[/LIST]

[B]One event, multiple announcement periods[/B]
[LIST]
[*]Set an event date/time and create separate promotion periods, each with its own frequency and message pool.
[*]Use quieter early reminders, more frequent announcements near the start, a time-sensitive “starting now” notice, and invitations while the event is underway.
[*]Configure one-time notices, lateness allowances, event duration and closing announcements.
[*]Support for daily, weekly, biweekly and monthly recurrence, including the last selected weekday of a month.
[/LIST]

[B]More flexible events and messages[/B]
[LIST]
[*]Faction rotations, rotating activities and cancellation exceptions.
[*]Named important times, such as ticket sales closing or gathering before a trial, with calendar/time controls.
[*]Dynamic substitutions including %eventwhen%, %eventtime%, %eventdate%, %eventcountdown%, %eventfaction% and %eventactivity%.
[*]Offset and named-deadline substitutions, including %eventtime-1h% and %eventcountdown:tickets%.
[*]Regular, month-final and all-events message groups.
[*]Test messages directly in your own chat with substitutions applied.
[/LIST]

[B]Better control over announcements[/B]
[LIST]
[*]Allowed announcement days/hours and optional daily limits, separately per period or shared across all periods for a command and guild.
[*]Incoming matching announcements from other players update your cooldowns, with channel/guild checks and support for changing countdowns and substitutions. Conservative spelling tolerance handles small text differences.
[*]Startup delay and spacing between scheduled commands help avoid a burst of reminders. Time-sensitive notices can bypass ordinary spacing.
[*]Updated status cards, readable countdowns, next-send information and Enable/Disable controls.
[*]Sliders for delivery intervals, cooldowns, schedule values and the pending-chat timeout.
[*]Guild-name mapping in portable transfers handles different guild-slot orders between players.
[*]Guild, Officer, Zone and Group chat output. Group chat uses /g.
[/LIST]

[B]Optional web companion[/B]
For a larger editor, message previews and a visual day-by-day schedule, visit [URL=https://scm.perdues.me]SmartChatMsg-Web[/URL]. Scheduling remains available directly in ESO.

Save full configurations or selected/all event exports to the optional server library. Load your own file first, review the selected events, and merge by guild name and command name while retaining unrelated local settings and recipient runtime history. Event bundles include all event delivery settings, including condensed formatting. Native ESO SCM_EXPORT text and web JSON event bundles are separate formats.

Library records are readable without a password. An optional overwrite password protects replacement of a saved record; replacing a protected record requires password confirmation. The server stores a hash of the secret. This is a web-library feature, with no addon password setting.

Install SmartChatMsg and run ESO with it enabled at least once, then exit ESO so it writes your SavedVariables file. Open live/SavedVariables/SmartChatMsg.lua in the web companion. Back up first, and close ESO before installing a downloaded replacement file.

[B]Important[/B]
SmartChatMsg prepares the message in chat; you still press Enter to send. It only runs while you are online with the addon loaded. Older schedule formats are not automatically converted; keep a backup before updating.

Recognized matching announcements from other players can update cooldowns and daily usage, including before you engage a command. Matching checks the correct channel and guild, handles supported dynamic tokens/countdowns and conservative small spelling differences, and adds randomized spacing between clients. Prepared or timed-out messages do not count as confirmed sends. Busy or player-edited chat remains protected.

[B]Requirements[/B]
ESO API 101051. Requires LibAddonMenu-2.0 (version 34 or newer) and LibAddonMenuDatePicker. No separate slider library is needed.
