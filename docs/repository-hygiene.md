# Repository file hygiene

The repository audit of 2026-10-20 found no tracked files generated by ESO installation or addon startup. No tracked-file removals are proposed.

## Source and shipped files to retain

- `SmartChatMsg.lua`, `SCM_SavedVars.lua`, and every Lua file listed in `SmartChatMsg.txt` are addon source, not player data.
- `SmartChatMsg.txt` is the ESO addon manifest.
- The versioned HTML guide and ReadMe files are intentionally shipped documentation. Although documentation can be generated during release preparation, it is not generated by installation/startup.
- The tests, fixtures, testing checklists, and scheduling design documents are development resources, not runtime output.

## Local artifacts to exclude if copied or created here

| Files | Reason |
| --- | --- |
| `SavedVariables/` at any depth | ESO per-account settings and saved state; the game normally stores these outside the addon source directory. |
| `AddOnSettings.txt` | Local ESO addon-selection settings, if a game profile is copied here. |
| `*.log`, `*.tmp`, `*.bak` | Local logs, temporary data, and backups. |
| `*.swp`, `*.swo`, `*~` | Editor swap files and backups. |
| `.DS_Store`, `Thumbs.db`, `Desktop.ini` | OS-generated folder metadata. |
| `__pycache__/`, `*.pyc` | Local Python test-runner caches. |
| Root `SmartChatMsg-*.zip` | Locally built release packages; distribute them separately from the source tree. |

The addon declares `SmartChatMsgSavedVars` through `ZO_SavedVars`; these account settings are separate from the similarly named Lua source module. A copied `SavedVariables/SmartChatMsg.lua` should be ignored, while the repository-root `SmartChatMsg.lua` must remain trackable.

These rules prevent new untracked artifacts from being added by ordinary Git commands. They do not remove files already tracked, erase local player settings, or prevent intentional force-adds. If a future audit finds tracked runtime files, list their exact paths for review before removing them from the repository.
